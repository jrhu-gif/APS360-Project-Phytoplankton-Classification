# Progress Report

Code, figures and results behind the APS360 progress report (main model: **HAB-Net**, a two-stream CNN; baselines: random forest and fine-tuned ResNet-18).

| Path | What it is |
|---|---|
| `code/` | Pipeline scripts, run in order `00` → `05` (see below) |
| `APS360_local.ipynb` | Notebook that runs the whole pipeline (steps 0–5, random forest, HAB-Net / ResNet-18 training, comparison), saved with outputs |
| `figures/` | Report figures. `.pptx` = editable source, `.pdf` = version used in LaTeX, `.png` = generated by the scripts |
| `audit_out/` | Data-audit summary: class counts, image-size summary, problem files (none found) |

## Pipeline (`code/`)

| Script | Step |
|---|---|
| `config.py` | All paths and settings (data folders, seed 42, splits, HAB classes, canvas 96 × 256, training runs) |
| `00_audit_data.py` | Checks both SYKE datasets (counts, corrupt / non-grayscale / duplicate images) and writes `audit_out/` |
| `01_prepare_splits.py` | 38 retained classes, label mapping between years, stratified 85/15 split, training cap 1,500 per class |
| `02_build_cache.py` | Otsu segmentation, 25 hand-crafted features, 96 × 256 image canvases (cached as `.npy`) |
| `03_random_forest.py` | Baseline 1: random forest (balanced class weights, trees chosen on validation macro-F1) |
| `models.py`, `04_train.py` | HAB-Net (1,216,135 parameters) and Baseline 2: ImageNet ResNet-18; training and evaluation |
| `05_compare.py` | Comparison tables (`comparison.csv`, `per_class_comparison.csv`), model choice, example figure |
| `plot_fig3.py`, `plot_figA2.py` | Redraw report Figure 3 (learning curves) and Appendix Figure A2 (examples) |
| `run.bat`, `start_jupyter_for_colab.bat` | Windows launchers: run one script, or start a local Jupyter runtime for Colab |

The data are not stored here; download both SYKE datasets (links in the main `README.md`) and set the paths at the top of `config.py`. `audit_out/index.csv` (33 MB) is not included; `00_audit_data.py` recreates it.
